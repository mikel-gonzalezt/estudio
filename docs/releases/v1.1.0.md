Estudio is an offline-first PDF reader for studying. Annotations are saved into the PDF itself, notes are Markdown files that work with Obsidian, flashcards follow the FSRS schedule, and it can read aloud with your system's offline voices.

**Try it:** open <https://mikel-gonzalezt.github.io/estudio/> in Edge or Chrome and click **Install**. Everything runs on your device. Nothing is uploaded, and there are no accounts.

## What's new since v1.0.1

### Security hardening
- **Links in notes:** only `http`, `https`, `mailto` and in-page links are kept. Links are decoded and parsed first, so entity-encoded `javascript:`, `data:` and similar tricks render as plain text. The same rule applies in the preview, Document mode, pasted HTML and the Word export.
- **External links** open in a new tab with `noopener noreferrer` and never navigate the app window.
- **Remote images in notes load only when clicked**, so a shared note can't act as a tracking pixel.
- **Content Security Policy:** `script-src 'self' 'wasm-unsafe-eval'`, `object-src 'none'`, `frame-src 'none'`, `form-action 'none'`, `base-uri 'self'`. It is sent as a header by the local server, which also sets `frame-ancestors 'none'`, and as a `<meta>` tag on GitHub Pages. No `unsafe-eval` is used.
- The README's "Privacy and security" section describes the threat model and its limits.

### Hosting
- The app is published on GitHub Pages at `/estudio/`, through a GitHub Actions workflow that runs the test suite before every deploy.
- The build takes a configurable base path (`BASE`), so the local Windows install keeps working at `127.0.0.1:4173`.
